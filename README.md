# وصلني بطريقك — لوحة الزبون (نسخة تشغيل أولية)

هذه نسخة Frontend كاملة للزبون، مقسمة إلى صفحات HTML منفصلة:
- تسجيل الدخول
- إنشاء الحساب
- OTP
- الرئيسية
- تسوكلي هنا
- السلة
- تحديد الموقع
- حجز مراجع
- توصيل حر
- طلباتي
- تفاصيل الطلب
- تتبع الطلب
- الإشعارات
- الحساب

## التشغيل
افتح `customer/login.html` عبر متصفح حديث.
لأفضل تجربة، شغّل مجلد المشروع بواسطة Local Server مثل Live Server في VS Code.

## بيانات التجربة
- عند إنشاء حساب، رمز OTP التجريبي هو: `123456`.
- البيانات محفوظة في LocalStorage على الجهاز.

## ما يحتاج Backend حتى يصبح نظامًا حقيقيًا
1. Firebase Auth أو Backend للحسابات.
2. Telegram Bot + سيرفر لإرسال OTP الحقيقي.
3. Firestore/Realtime Database للطلبات.
4. Firebase Storage للمرفقات والصور.
5. خرائط تفاعلية فعلية وحساب مسافة/أجرة من الإحداثيات.
6. Realtime tracking للكابتن.
7. Push Notifications + صوت.
8. توليد PDF حقيقي من الفاتورة.
9. نظام صلاحيات Customer/Captain/Admin.
10. لوحة الإدارة ولوحة الكابتن وربطهما بالطلبات.

## نطاق البداية
واجهة المشروع مصممة لتطبيق خدمة داخل الناصرية مع نطاق ابتدائي 20 كم، ويمكن لاحقًا جعل الرقم إعدادًا من لوحة الإدارة.
